## 4. Rules the AI tools worked under

- **No source, no answer.** No agent may write Quran or hadith text from memory, in code, prompts, tests or seed data; only the approved sources are used (`AGENTS.md`, "Islamic content rules").
- **Copy by script, never by hand.** Source text is copied from the saved page or the pinned data file by the tools in `backend/session_moral_context/content/tools/`, with a SHA-256 check. Reason: the Claude `Write` tool was seen to reorder Arabic combining marks (`docs/hackathon/build-progress.md`, "Rules").
- **People review the content.** Every one of the 273 items was checked against its source by a named team member before it could be served (`content/reviewed.json`; the reviewers are listed in the README, section 2.3). Organiser rulings on each source are in `docs/hackathon/content-approach-plan.md` section 12.
- **Review before merge.** An Opus reviewer read every non-trivial diff, and the lead merged each task branch into `hackathon` through a pull request (PRs #49 to #62).
- **No secrets, no real data.** Keys stay in `.env` (never committed); the brain never receives keys or children's data; the demo uses 40 synthetic families (`backend/demo/content.py`).
